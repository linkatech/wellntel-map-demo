# Agent Instructions

## No self-testing

Do not test your own work unless it is definitely necessary for the task at hand,
or the user explicitly asks for it.

- Do not open the browser, take screenshots, or click through the UI to verify changes.
- Do not run the dev server, test suites, type checks, or builds just to confirm an edit worked.
- Make the change, then stop and report what you changed. The user will check it.
- Testing is OK only when the task itself requires it (e.g. diagnosing a bug you cannot
  locate by reading the code) or when the user says "test it", "verify it", or similar.
- If you did not test, say so plainly. Never claim something is fixed or verified without
  having actually checked it.
